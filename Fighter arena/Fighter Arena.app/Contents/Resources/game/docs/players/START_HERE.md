# Start Here

This page is for someone who just wants to open the game with the least stress.

## Fastest way on Mac

In the project folder, double-click:

- `Fighter Arena.app`
- or `Launch Fighter Arena.command`

That starts the server and opens the browser automatically.

## Terminal way

```bash
cd "/path/to/Fighter arena"
python3 server.py 4174
```

Then open [http://127.0.0.1:4174/](http://127.0.0.1:4174/).

## What to do after the game opens

1. Read the **Beginner Guide** panel if it appears.
2. Click **Single Player** first if you want a safe practice mode.
3. Click inside the game world to lock the mouse.
4. Press `Esc` any time to pause.
